Currently, I am working on my personal project [LibraryTools](https://github.com/Matthew2077/LibraryTools) : a lightweight, API-first backend for managing and structuring knowledge through notes, categories, and tags.

## About LibraryTools:
Current version: 1.0 | 
Full tecnical info: [version 1.0](https://github.com/Matthew2077/LibraryTools/blob/main/v1_review.md)

Features:

- Create, edit, read, and delete notes
- Manage note status (draft, published, archived)
- Create, edit, read, and delete categories
- Create, edit, read, and delete tags
- Tags have a many-to-many relationship
- Create, edit, read, and delete users
